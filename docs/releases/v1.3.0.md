这一版：新建的待办带上了看得懂的编号，标题栏也标出了当前版本号。

主要变化

- **新建的待办自动生成可读编号**（如 `cl-001`、`plan-002`）：编号 = 分类前缀 + 3 位序号，
  不再是 `imtvb3v58-mqn9hs` 那种随机串
- **按分类分别排号**：同一个分类里接着往下排（第二条是 `cl-002`），序号不会撞
- **编号跟 AI 那边（小刀技能）用的是同一套规则**：桌面端建的和小刀建的不会有两种写法，
  跨对话说"cl-003 那条"时双方指的就是同一条
- **标题栏上显示当前版本号**（如 `v1.3.0`）：不用再翻「设置 → 关于」确认自己装的是哪一版
- 自己加的分类仍用随机编号

说明

- 编号只往上涨、不回收：删掉一条之后，它的号不会被后来的条目顶替
- 数据在 `%APPDATA%\小刀工作台\`，升级不会动数据
- 安装包没有代码签名，首次运行 Windows 会拦一下，点「更多信息 → 仍要运行」
