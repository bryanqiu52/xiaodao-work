小刀工作台的第一个公开版本。

从这一版起，软件会自己检查更新：每天自动查一次有没有新版本，有的话提示你这版改了什么，
点一下它自己下载安装完、重启生效 —— 不用再去网页上找安装包。

主要变化

- 支持自动更新，更新包带签名校验（别人换掉下载链接里的包也装不上）
- 改为开源发布，MIT 许可，源码在 GitHub 上
- 内置壁纸和 md 查看器随安装包一起提供（装完就在，不用另找）：
  - 壁纸：设置 → 外观 → 背景 里直接挑，也可以换成你自己的图
  - md 查看器：装完在安装目录 `tools\MD-Preview.exe`，点待办里的 md 产出就能直接预览。
    想换成自己惯用的查看器，到「设置 → 打开产出」里指定。
    （它是第三方开源工具 [md-preview](https://github.com/fisher158163/md-preview)，MIT 许可，
    许可原文随包附在 `tools\MD-Preview-LICENSE.txt`）

升级注意

- 如果你之前装过 1.1.x：那个版本还没有更新功能，所以这一版要手动下载安装一次。
  装完之后，以后的版本就能自动更新了。数据不会动（还在原来的位置）。
- 卸载或覆盖安装都不会删除数据。数据在 `%APPDATA%\小刀工作台\`，
  待办清单的位置可以在「设置 → 待办」里看到。
- 安装包没有代码签名，首次运行 Windows 会拦一下，点「更多信息 → 仍要运行」。
