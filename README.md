# 小刀工作台

一个常驻托盘的 Windows 桌面小工具，把「待办 + 番茄钟 + 记账 + GitHub 热榜 + 回顾」装进一个窗口。
按 `Ctrl+Shift+Space` 随时唤出来，用完按 `Esc` 或点托盘缩回去。

它的特别之处是**待办清单就是一个普通的 JSON 文件** —— 你自己看得懂，AI 也读写得了。
所以它天生适合"人机交接活"：你记一句，AI 接着干，干完把产出挂回来，两边看的是同一份数据。

## 它能干什么

| 面板 | 做什么 |
|:--|:--|
| **待办** | 归属分「我的 / AI 的」、领域分类、权重、期限；搜索、筛选、按期限分组；**撤销**（点按钮或 `Ctrl+Z`）；产出文件和关联待办都能挂 |
| **番茄闹钟** | 专注 / 短休 / 长休循环，环形进度，到点系统通知 + 提示音；可以挂到某条待办上，记录时间到底花哪了 |
| **记账** | 收支流水、月切换、分类占比、与上月对比、搜索；金额按"分"存整数，统计不会出浮点尾巴 |
| **GitHub 热榜** | 按语言和时间范围看热门仓库，点一下跳浏览器 |
| **回顾** | 本周 / 本月的完成情况、平均耗时、专注时长、按领域分布 |

还有一些用久了才体会得到的小设计：贴边自动收起、窗口圆角与不透明度可调、内置壁纸、
每日自动备份（含设置和数据）、全局快捷键可换、深浅主题跟随系统。

## 下载与安装

到 [Releases](https://github.com/bryanqiu52/xiaodao-work/releases) 下最新的
`xiaodao_work_<版本>_x64-setup.exe`，双击安装。

- 要求：Windows 10 / 11（64 位）
- 安装包**没有代码签名**，首次运行 Windows SmartScreen 会拦一下 ——
  点「更多信息 → 仍要运行」即可。这是个人开发者的通行门槛，不是软件有问题。

## 数据放在哪

| 什么 | 在哪 |
|:--|:--|
| 设置、日志、备份、壁纸、记账、专注记录 | `%APPDATA%\小刀工作台\` |
| 待办清单 | 默认也在上面那个目录里的 `待办.json`，**可以在「设置 → 待办」里改到任何位置** |

便携版（exe 旁边放一个名为 `portable` 的空文件）会把数据放在 `exe目录\data\`，适合放 U 盘。

## 隐私

**你的数据不会离开这台电脑。** 全部存在本地文件里，没有账号、没有云同步、没有埋点。

仅有的两次联网：

1. **GitHub 热榜** —— 你打开那个面板时才会去请求 GitHub 的公开接口；
2. **检查更新** —— 每天最多一次，去 GitHub 读本仓库的最新版本号。

两次都只读取公开信息，**不会上传你的任何数据**。

## 更新

应用每天最多自动查一次新版本（也可以在「设置 → 关于 → 检查更新」手动查）。
发现新版本会提示你改了什么，点「立即更新」它自己下载安装完、重启完成 —— 不用手动重装。

## 反馈

- 遇到问题或想提建议：[开一个 Issue](https://github.com/bryanqiu52/xiaodao-work/issues)
- 提问题请带上：版本号（设置 → 关于 里能看到）、你做了什么、期望是什么、实际是什么
- 应用日志在 `%APPDATA%\小刀工作台\logs\xiaodao_work.log`，贴日志能省很多来回

## 开发

技术栈：Vue 3 + TypeScript + Vite 前端，Rust + Tauri 2 外壳。业务逻辑全在前端 `src/core/` 里（纯 TS），
Rust 侧只做"读文件、写文件、监听、托盘、通知"这类系统能力 —— 一句话：**Rust 不碰业务语义**。

```bash
npm install
npm run tauri:dev      # 开发（前端热更新 + Rust 重编）
npm run tauri:build    # 出安装包
```

> ⚠️ 出正式包**只能用 `npm run tauri:build`**。直接 `cargo build --release` 会把开发服务器地址打进包里，
> 双击只会弹「无法访问此页面」。

发版流程、版本号要改哪几处、更新密钥怎么管：见 [RELEASE.md](RELEASE.md)。
